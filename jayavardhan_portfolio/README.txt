Publish with GitHub Pages:
1. Upload index.html and README.txt to the root of your public GitHub repository.
2. Open Settings > Pages.
3. Select Deploy from a branch, branch main, folder /(root), then Save.
4. Wait for the deployment to complete and open the published URL.
