VUPPU JAYAVARDHAN — PORTFOLIO

Files:
- index.html: complete responsive portfolio website.

Preview:
1. Extract the ZIP.
2. Open index.html in Chrome.

Publish free with GitHub Pages:
1. Sign in to GitHub and create a new public repository named jayavardhan-portfolio.
2. Upload index.html to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for the published URL shown in the Pages section.

Before submitting:
- Check your name, college, email and LinkedIn link.
- Replace or expand the skills/projects section only with work you have actually completed.
- Open the published URL on your phone to test it.
